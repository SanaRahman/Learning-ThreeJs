
# Three.js Project with Dat.GUI Integration

This project showcases a Three.js application with Dat.GUI for interactive controls.

## Getting Started

To run this project, follow these steps:

### Prerequisites

Make sure you have Node.js and npm installed on your machine.

### Installation

Install the required dependencies using npm:

```bash
npm install --save dat.gui
```

### Running the Project

Run the following command to start the development server:

```bash
npx serve .
```

Open your browser and navigate to [http://localhost:3000](http://localhost:5000) to view the application.

## Usage

The application integrates Dat.GUI for interactive controls. Explore the controls to customize the scene.
